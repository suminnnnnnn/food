# 상세페이지 품질 감사 · 개선 제안 (전문가 3인 종합)

## 한 줄 결론
데이터 파이프라인은 견고해졌다(가격 근거 강제로 **환각 0**, review 43/44). 문제는 **프레젠테이션**이고 두 종류다:
- **(A) 좋은 데이터를 숨기는 라우팅 버그** — 만들어 놓은 리뷰가 화면에 안 뜬다.
- **(B) 신뢰를 깎는 "가짜" 요소** — 유일 차별점이 신뢰인 앱이 스스로 신뢰를 훼손한다. **런칭 블로커.**

> 종합 방향: **가짜(별점·할인·인증)를 지우고, 진짜(유튜버 리뷰·장면 딥링크·영업시간)를 켜라.**

## 전문가 합의 (교차 검증된 것)

1. **대표영상 = 조회수 1등 버그 (3인 전원).** `activeVideoIndex=0` + `sortedVideos`가 view_count DESC → 항상 최다조회 영상을 보여준다. 그런데 enrich 데이터는 다른 영상에 붙어 있거나(해뜨는식당, 리트라이가 저조회 영상에 저장) 최다조회가 쓰레기(스시어항 자체계정 개그 쇼츠)다. **근본 원인.**
2. **게이트가 "식당 일치"만 보고 "미식 리뷰성"은 못 본다 (데이터+프로덕트).** 스시어항(코미디)·꽃보다피자(ASMR, conf 0.5 턱걸이 통과)가 리뷰인 척 통과.
3. **pick 코멘트가 날것/길다 (프론트+데이터).** 프롬프트 "30자"를 코드가 `slice(120)`로만 잘라 유튜버 발화가 비문·구어체로 그대로 노출("금막이랑 기름이 있으니까 훨씬 더…" 43자), line-clamp-1로 중간에 잘림. 14~27곳.

## 프로덕트가 발견한 신뢰 역행 요소 (신규·고심각, 런칭 전 제거 대상)

4. **하드코딩 별점** (`getRestaurantRatings`) — 네이버/카카오 별점을 상수로 지어내 상단에 크게 표시. 실제와 다르면 앱 신뢰 붕괴. "자체 리뷰 없음" 컨셉의 자기부정.
5. **가짜 밀키트 + 가짜 할인** (`getMockProduct`, `price*1.2` 취소선) — 존재하지 않는 "{식당명} 시그니처 밀키트"와 없는 할인율을 그려 쿠팡으로. 명백한 기만. 44곳 대부분 해당.
6. **무영상 매장 "미쉐린·블루리본 공인" 문구** — 영상 없으면 무조건 "검증 기관 공인 미식 성지" 출력. 허위 인증.
7. **"🔥 CREATOR PICK" 배지 전 매장 남발** — 스시어항(개그)에도 붙어 선별 신호가 소음.
8. **quote='정보 없음' 리터럴 노출** — hours는 `checkAvailability`로 거르는데 quote/review는 방어 없어 "정보 없음"이 리뷰인 척 큰따옴표로 출력.
9. **best_food_scenes 딥링크가 메인 상세페이지(`/restaurants/[id]`)엔 없다** — `RestaurantInfoCard`에만 구현. 최고 자산이 SEO/공유 페이지에서 사장.
10. **"Pick" 이중 의미** — Creator "콕 집은 메뉴"(실제 먹은 것) vs Menu 섹션 "유튜버 Pick"(실은 menu_info 전체, 앞 2개 임의 PICK 배지).

## 우선순위 로드맵

### Tier 0 — 런칭 전 필수 (정직화, 반나절, 최고 ROI — 대부분 "제거")
- 하드코딩 별점 제거(4) · mock 밀키트 가짜할인 제거/정직화(5) · 무영상 "미쉐린 공인" 허위문구 교체(6)
- "CREATOR PICK" 무조건 배지 → 근거 기반 배지("[성시경] 추천", "여러 유튜버 추천")(7)
- quote/review `'정보 없음'` 필터(8)

### Tier 1 — 핵심 품질
- **대표영상 선택 수정** — enrich된/리뷰적합 영상을 activeVideo 기본값으로(1). 즉효: `sortedVideos`를 `has-insights 우선, 그다음 view_count`로. 근본: 대표영상 id 저장.
- **게이트에 리뷰성 판정** — `content_type`/`tasting_review_score`/`creator_is_independent` 추가, 코미디·홍보·순수먹방 보류(2). 대표 재선정과 결합.
- **영업시간 44곳 100% 백필** — `kakao_place_id` 있는 곳 Kakao/검색그라운딩(`enrich_restaurants.mjs:searchDetails` 재사용)로(결손).

### Tier 2 — 마감 품질
- pick 코멘트 정제(프롬프트 "정제된 한 문장 35자" + slice 하향 + line-clamp-2)(3)
- picks 가격을 카드 상단 "대표 메뉴 ○○원"으로 승격(가격 결손 완화)
- best_food_scenes 딥링크를 메인 상세페이지에도 이식(9)
- "Pick" 이중 의미 정리(10) · 사회적 증거 헤더("유튜버 N명 · 누적 조회 XX만") · quote 히어로 승격 · "AI 꿀팁"→"영상 속 꿀팁" 출처 귀속

## 즉시 착수 권고
**Tier 0 정직화 + Tier 1 대표영상 수정**을 먼저. 이유: (a) 가짜 요소는 있는 진짜 자산까지 "못 믿을 앱"으로 오염시켜 순증을 상쇄한다. (b) 대표영상 버그는 이미 만든 데이터(리트라이 회수분 전부)를 화면에 되살리는, 코드량 최소·영향 최대의 수정이다.
