# /validate — 하네스 검증 실행

현재 단계의 하네스를 실행하여 통과 여부를 확인한다.
사용법: `/validate [H-1|H-2|H-3|H-4|H-5|H-6]`

하네스를 통과하지 못하면 다음 단계로 넘어가지 않는다.

## H-1: 지도 렌더링
```
검증 1: 초기 렌더링 시 /api/restaurants 요청 확인 (브라우저 네트워크 탭)
검증 2: 지도 드래그 후 새 bounds로 재쿼리 발생, 중복 요청 없음
검증 3: 줌 10 이하 → CustomOverlayMap DOM에 없음 확인
검증 4: 줌 14 이상 → 개별 마커 DOM 렌더링 확인

실패 기준: 16만 건 전체가 한 번에 로드되는 경우
```

## H-2: 필터 시스템
```
검증 1: 초기 상태 → 전체 식당 일반 핀 마커만 표시
검증 2: 유튜브 ON → 유튜버 원형 마커, 나머지 opacity 0.3 이하
검증 3: 복수 필터 선택 → 두 소스 모두 하이라이트
검증 4: 필터 해제 → 즉시 기본 상태 복귀 (깜빡임 없음)

실패 기준: 필터 전환 시 전체 마커가 재렌더링되어 깜빡이는 경우
```

## H-3: 상세 카드
```
검증 1: 마커 클릭 → 슬라이드업 애니메이션 200ms 이내 시작
검증 2: 유튜브 태그 → 썸네일 + 재생 버튼, 클릭 시 새 탭 열기
검증 3: 복수 영상 식당 → 가로 스크롤 렌더링
검증 4: 미슐랭 태그 → 배지 + 연도 표시
검증 5: 카드 닫기 → 선택 해제, 마커 원복

실패 기준: 다른 식당의 정보가 표시되는 경우
```

## H-4: 트렌딩 티커
```
검증 1: /api/trending 응답 → 최근 7일 view_count 상위 5개 포함
검증 2: 응답 헤더 Cache-Control max-age=3600 확인
검증 3: 티커 자동 슬라이드 3~5초 간격
검증 4: 소스 코드에 하드코딩된 문자열 없음

실패 기준: 빈 티커 또는 하드코딩 텍스트 표시
```

## H-5: 벡터 검색
```
검증 1: "조용한 일식집" 쿼리 → 일식 카테고리 식당 상위 노출
검증 2: 검색 결과 지도 마커 + 사이드 리스트 동기화
검증 3: 검색 초기화 → 기본 지도 상태 복귀
검증 4: 빈 결과 → 안내 메시지 표시

실패 기준: 쿼리와 무관한 식당이 상위 노출
```

## H-6: 디자인 품질
```
검증 1: border-left/right > 1px 패턴 소스 내 없음
검증 2: background-clip: text + gradient 없음
검증 3: 금지 폰트 미사용 (Inter, Roboto, Arial, DM Sans 등)
검증 4: 순수 #000 / #fff 미사용
검증 5: 카드 안에 카드 중첩 없음

실패 기준: 위 패턴 중 1개 이상 발견
```
